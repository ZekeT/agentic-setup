# Issue tracker: local Markdown

Use Matt's installed setup-matt-pocock-skills/issue-tracker-local.md contract.
Specs live at .scratch/<feature>/spec.md and tickets at
.scratch/<feature>/issues/<NN>-<slug>.md. Keep existing task formats and statuses.
Update acceptance checkboxes and status as work is completed; report actual checks
and gaps. Distinguish implementation, review, publication and team delivery.
This tracker belongs to development of the setup tool itself. The original v3
rebuild is recorded in .scratch/minimal-starter/spec.md; new features get their own
scoped spec and tickets, referencing [product direction](../product-direction.md).
Target projects use their own tracker and do not inherit this repository's tickets.
