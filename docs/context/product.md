# Product context

Agentic Starter configures Matt Pocock's development workflow without adding a
runtime gate. A consumer is an application receiving guidance and selected skills.
A minimal transition disconnects recognized old starter overhead while preserving
application work. A selective update changes only requested starter guidance.
The installer lives in an external source checkout; everyday work uses native
checks and upstream skills. See agentic-starter-directional-change-handover.md for
the agreed decisions and exclusions.
